# Sri RBP Communications Website

A simple, responsive corporate website built using:

- HTML5
- CSS3
- JavaScript

## Features

- Responsive Design
- Single Page Layout
- Smooth Scrolling
- Product Cards
- Contact Section
- Lightweight
- Ready for Vercel Deployment

Simply open `index.html` in your browser.
